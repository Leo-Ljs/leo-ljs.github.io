About

关于这个小站

这是 Leo 的个人主页，用最普通的 HTML、CSS 和 JavaScript 写成。没有构建步骤，没有第三方脚本，也没有需要维护的后端。打开 GitHub Pages，它就在那里。

做这个站的原因很简单：想要一个干净、可控、不会突然消失的地方放东西。网盘的数据就是一份 JSON，页面只是把它渲染出来；想改内容，用可视化编辑器改完导出、上传，就完成了。

轻，是真的轻 没有框架和外部依赖，首屏只加载几个本地文件。
下载不经过本站 所有文件都跳转到外部网盘，GitHub Pages 只负责展示目录。
数据即文件 一份 data.json 就是全部内容，随时可以备份、迁移或手改。
